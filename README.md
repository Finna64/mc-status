**MC SERVER STATUS**

Constructs the structure of a webpage that fetches the number of players currently online on your Minecraft Server.

**OVERVIEW**

I wanted to know when my friends were online on our group's Minecraft Server, so I built this simple webpage to fetch and display the current number of players online. NOTE: to use this project, you will have to change the IP address in the index.html file to the IP address of your friend's Minecraft server.

**FEATURES**
- JavaScript script fetches JSON data from web hosted mcsrvstat API, and filters through data to find the number of players currently online.
- HTML structure displays the number of currently online players on your server.

**TECHNOLOGIES**

HTML - web page structure
CSS - web page stylin
API - retrieves data from mcsrvstat
JavaScript - API integration
